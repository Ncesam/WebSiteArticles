## 📌 Описание проекта

**WebSiteArticles** — это полнофункциональное веб-приложение для создания, редактирования и отображения статей. Проект включает в себя как клиентскую, так и серверную части, что обеспечивает гибкость и масштабируемость.

---

## 📁 Структура проекта

* `frontend/` — клиентская часть приложения, разработанная с использованием TypeScript.
* `backend/` — серверная часть, реализующая бизнес-логику и взаимодействие с базой данных.
* `.vscode/` — настройки среды разработки Visual Studio Code.
* `docker-compose.yaml` и `docker-compose.debug.yaml` — файлы для контейнеризации и оркестрации сервисов с помощью Docker Compose.
* `Makefile` — сценарии автоматизации задач разработки и развертывания.
* `.gitignore` — список файлов и папок, игнорируемых системой контроля версий Git.

---

## 🚀 Быстрый старт

1. **Клонируйте репозиторий:**

   ```bash
   git clone https://github.com/Ncesam/WebSiteArticles.git
   cd WebSiteArticles
   ```

2. **Переключитесь на ветку `Dev`:**

   ```bash
   git checkout Dev
   ```

3. **Запустите приложение с помощью Docker Compose:**

   ```bash
   docker-compose up --build
   ```

   Это развернет все необходимые сервисы, включая фронтенд и бэкенд части приложения.

---

## 🛠️ Конфигурация

* **Docker Compose**: используется для управления многоконтейнерными приложениями. Файлы `docker-compose.yaml` и `docker-compose.debug.yaml` содержат конфигурации для стандартного и отладочного режимов соответственно.
* **Makefile**: содержит команды для автоматизации задач, таких как сборка, тестирование и развертывание приложения.
